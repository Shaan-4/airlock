Airlock

A prompt-injection defense for AI agents that use tools. Choose a task, then choose an attack to hide in the email, web page or calendar event that the task reads. All three agents use the same scripted model, which does the task correctly but also follows any instruction hidden in the content. The only difference is how each agent is built. Source on GitHub

The scripted model follows every injected instruction, so the plain agent's 100% is a worst case. Real models get fooled less often. The one attack Airlock lets through, poison_time, puts a fake meeting time inside the email the user asked it to read, and tracking where data came from can't tell it apart from the real time.
